# Lienzo 0.1.1

Esta versión pule la experiencia cotidiana de dibujo después de probar Lienzo
en Windows y macOS.

## Novedades

- Zoom natural con `Ctrl + rueda` en Windows y Linux, y `Cmd + rueda` en macOS.
- Selector de grosor integrado para lápiz, pincel, borrador y formas.
- Tamaño ajustable de 1 a 50 px; el borrador admite hasta 100 px.
- Miniatura rediseñada para integrarse con cada tema y mostrar dimensiones y zoom.
- Barra de desplazamiento clara y con contraste en los temas claros de Windows.
- Correcciones visuales y de coherencia en diálogos y controles.

## Descargas

- macOS Apple Silicon: ZIP portable o DMG.
- Windows x86_64: ZIP portable o instalador `Setup.exe`.
- Linux x86_64: AppImage portable o paquete DEB para Debian/Ubuntu.

Los binarios no tienen firma comercial, por lo que macOS Gatekeeper o Windows
SmartScreen pueden mostrar una advertencia. Use `SHA256SUMS.txt` para comprobar
la integridad de cada descarga.
